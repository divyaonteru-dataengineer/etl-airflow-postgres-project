# etl-airflow-postgres-project
## Tech Stack
- Python
- Apache Airflow
- PostgreSQL

## Project Overview
This project demonstrates an ETL pipeline that extracts data from CSV files, transforms the data using Python, and loads it into PostgreSQL using Apache Airflow.

## Features
- Automated scheduling
- CSV ingestion
- Data cleaning
- PostgreSQL integration

## Architecture

CSV → Python → Airflow → PostgreSQL
